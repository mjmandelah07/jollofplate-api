# JollofPlate — Logo Design Prompts (ChatGPT / Image AI)

Use these prompts to generate logo concepts for **website**, **socials**, and export as **PNG** / **SVG**.

## Brand constraints (always include)

```text
Brand name: JollofPlate
Tagline: Every Plate Tells a Story.
Personality: warm, vibrant, authentic, modern, premium, community-driven.
Colors:
- Primary Jollof Red #C0392B
- Secondary Golden Rice #F39C12
- Accent Fresh Green #145A32
- Background Warm Cream #FFF8F0
- Text Charcoal #222222
Typography vibe: bold modern sans (Poppins-like) for the wordmark.
Must be readable small, work on light and dark backgrounds, no clutter.
```

---

## 1. Master logo prompt (best starting point)

```text
Design a modern premium logo for "JollofPlate", a digital-first Nigerian jollof food brand.

Concept:
- Clean wordmark "JollofPlate" in bold modern sans-serif
- Optional simple icon: stylized plate + steam, or abstract jollof rice grain / flame-plate mark
- Colors: jollof red (#C0392B) and golden rice (#F39C12), with optional fresh green accent (#145A32)
- Style: warm, authentic, premium, mobile-app friendly
- Flat vector look, high contrast, minimal detail
- No photorealistic food, no busy patterns, no 3D gloss overload
- No tagline in the main mark (keep tagline separate)
- Transparent background
- Centered composition, suitable for website header and app icon

Deliver as a clean logo lockup (icon + wordmark).
```

## 6. Prompt for SVG-ready output

ChatGPT images are usually raster. Ask for SVG in a **code / design** follow-up:

```text
Convert this JollofPlate logo concept into a clean SVG-friendly design description:
- Simple geometric shapes only
- No tiny details
- 2–3 colors max
- Clear icon + wordmark proportions
Then provide SVG code for:
1) icon-only
2) horizontal lockup
Use exact hex colors #C0392B, #F39C12, #145A32 where needed.
Optimize for web (small file, crisp at all sizes).
```

**Or in Figma / Illustrator after generating PNG:**
1. Recreate with pen tool / shapes (recommended for true SVG)
2. Export SVG + PNG (@1x, @2x, @3x)

---

## 7. Export checklist

| Use | Format | Size / notes |
|-----|--------|----------------|
| Website header | SVG + PNG | ~160–240px wide; transparent |
| Favicon | PNG / ICO / SVG | 32, 48, 180 (apple touch) |
| Social avatar | PNG | 512×512 or 1024×1024 |
| Social cover | PNG | 1500×500 (FB) / 1584×396 (LinkedIn) as needed |
| App icon | PNG | 1024×1024 |
| Print / dark bg | PNG/SVG | white mono version |

### PNG export tips
- Transparent background
- Export 1x, 2x, 3x
- Keep a square icon master at **1024×1024**

### SVG tips
- True vector recreation beats “AI PNG → auto trace” for quality
- Outline text (or use a web font for wordmark in code)
- Remove unused points; keep paths simple

## 8. Negative prompt / avoid list

```text
Avoid: complex illustrations, realistic rice photos inside logo, too many colors, thin hairlines, script fonts, clipart style, 3D chrome effects, drop shadows that break at small size, tagline inside the main logo mark, watermarks, mockups with phones unless asked.
```
